# 어디갈까? — 국내여행 랜덤 추천 서비스

시안을 HTML + CSS + Vanilla JS 만으로 구현한 프로젝트입니다. 빌드 도구·프레임워크·외부 라이브러리를 쓰지 않습니다.

## 실행

```bash
cd s
python3 -m http.server 8777
# http://localhost:8777
```

`index.html` 을 파일로 바로 열어도 동작합니다. (`localStorage` 사용 때문에 로컬 서버 실행을 권장)

## 폴더 구조

```
s/
├── index.html          # 마크업 + SVG 아이콘 스프라이트
├── css/
│   ├── reset.css       # 브라우저 기본 스타일 초기화
│   └── style.css       # 디자인 토큰 → 컴포넌트 → 레이아웃 → 반응형
├── js/
│   └── main.js         # 렌더링 + 이벤트 (IIFE, 전역 오염 없음)
├── images/             # 시안에서 추출한 이미지 자산
└── README.md
```

## 구현된 기능

| 기능 | 설명 |
| --- | --- |
| 랜덤 여행 뽑기 | 주사위가 흔들리며 지도 마커가 감속하듯 순환하다 한 곳에 당첨 |
| 지도 마커 | hover 시 툴팁(지역 · 소요시간), 클릭 시 우측 카드 전체 갱신 |
| 교통수단 선택 | 자동차 / KTX / 고속버스 / 비행기 — 선택 시 소요시간·요금 즉시 반영 |
| 운행 없음 처리 | 해당 여행지에 없는 수단은 자동 비활성 (예: 제주 = 비행기만) |
| 교통 정보 | 이용 가능한 수단만 렌더링, 행 클릭으로도 수단 전환 |
| 출발지 설정 | 드롭다운 · 외부 클릭/ESC 로 닫힘 · 내 위치 사용 토글 |
| 찜하기 | 하트 토글 + 헤더 뱃지 카운트, `localStorage` 에 저장 |
| 인기 지역 | 클릭 시 해당 여행지로 이동, 현재 선택 지역 하이라이트 |
| 테마 캐러셀 | 좌우 화살표 이동, 양 끝에서 자동 비활성 |
| 접근성 | 키보드 포커스, `aria-pressed` / `aria-expanded` / `aria-current`, `prefers-reduced-motion` 대응 |

## 이미지 교체

`images/` 안의 파일은 **시안 캡처(1402×1122)에서 잘라낸 것**이라 원본 해상도가 낮습니다.
특히 다음 두 곳은 원본이 56×56 이라 크게 표시하면 흐릿합니다.

- `mk-seoul.png` (서울), `mk-sejong.png` (세종) — 우측 큰 카드에 쓰일 때

권장 사이즈 — 히어로 `548×340`, 마커 `112×112`, 테마 카드 `254×144`, 인기지역 썸네일 `72×72` (2배수 기준)

## 알려진 제약

- **테마 캐러셀**: 카드가 6개라 데스크톱 넓은 화면에서는 전부 보여 화살표가 비활성 상태입니다. `THEMES` 배열에 항목을 추가하면 바로 스크롤됩니다.
- **반응형**: 1360 / 1180 / 900 / 620px 브레이크포인트를 작성했으나, 데스크톱 폭에서만 실제 브라우저로 확인했습니다.
- 지도는 시안의 3D 렌더 이미지를 그대로 사용합니다. 시도별 영역 hover 가 필요하면 SVG 행정구역 지도로 교체해야 합니다.
